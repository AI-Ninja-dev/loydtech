# Design and launch review

Direction: enterprise connected operations, with original Loydtech typography and content. Disrupt-X informed the platform-led navigation and solution storytelling; its branding, copy and product claims were not reused.

Visual system: Geist typography, forest-charcoal hero and CTA sections, emerald actions, pale sage previews, white editorial pages, restrained rounding. Wide headings, native navigation and readable content precede motion. The generated hero reference was reviewed before coding. Buildings remain an illustrative background rather than a claim of installed projects.

Information audit: the unfinished local draft used cybersecurity-only positioning, fake contact data, unsupported metrics, testimonials and certification sections. These were replaced with the actual repository's connected-operations direction, scoped capability descriptions and a truthful email handoff. Existing local work was saved in a preservation commit before changes.

Remaining owner inputs: valid logo file; verified contact mailbox; exact Sentinel 365 release status and integration list; real customer evidence; approved commercial/service terms. No public release was performed.

Final validation: Next.js 16.3.5 static production build and TypeScript checks passed, lint passed, and all three browser suites passed. These suites cover all pages, internal links, platform modes, enquiry prefill/download, keyboard menu behaviour and responsive overflow. No enquiry was sent. Dependency audit reports zero vulnerabilities after the update. Desktop and mobile screenshots were inspected.
